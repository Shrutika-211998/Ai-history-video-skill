**AI Tools:** Veo 3 / Kling / Seedance / Hailuo  
**Language:** Hindi (Voiceover) + English (Video Prompts)

---

## WHEN TO USE THIS SKILL

Use this skill whenever the user asks for:
- AI video scenes for a historical topic (Indian history)
- Scene-by-scene breakdown for Veo/Kling/Seedance
- Video prompts with voiceover for a YouTube channel
- History series like Shivaji Maharaj, Maratha Empire, Jyotirlinga, etc.

---

## CORE RULES — ALWAYS FOLLOW

### 1. RESPECT & NAMING
- NEVER use एकेरी उल्लेख (single name reference)
- Always use: **छत्रपती शिवाजी महाराज** / **महाराज** / **छत्रपती शिवाजी महाराजांनी**
- Same rule for all historical figures based on user's guidance
- If user says "no single name reference" for any character → strictly follow

### 2. VIDEO FORMAT
```
Default Shorts:  Vertical 9:16
Default Long:    Landscape 16:9
Default Length:  8 seconds per scene (strictly)
Style:           Disney Pixar Inspired Ultra Realistic 3D
Quality:         8K Ultra HD, HDR, Masterpiece
```

### 3. NO LIP SYNC — MANDATORY
Every prompt MUST include:
```
No character speaks, no lip movement, no mouth animation, only background narration.
```
All emotions via: body language, eye contact, gestures, posture — NEVER dialogue.

### 4. VOICEOVER TIMING
```
8 sec scene  = 18–22 Hindi words MAX
10 sec scene = 22–26 Hindi words MAX
12 sec scene = 26–30 Hindi words MAX
```
Always count words before finalizing. If it exceeds limit → trim ruthlessly.

### 5. VIOLENCE LEVEL (ask user before starting)
```
Level 1 - Kids:       No violence. Only gestures, teamwork, flags.
Level 2 - General:    Shield clashes, sword sparks, defensive moves. No blood/gore.
Level 3 - Historical: Realistic battle action. Minimal blood. No dismemberment/horror.
```
Default = Level 2 unless user specifies.

## VIDEO PROMPT STRUCTURE

Every prompt must contain these 6 layers in order:

### Layer 1 — Style Declaration
```
Disney Pixar inspired ultra-realistic cinematic 3D animation, aspect ratio [X], 
set in [LOCATION], [REGION], year [YEAR]. No character speaks, no lip movement, 
no mouth animation, only background narration.
```

### Layer 2 — Environment
```
[Describe setting: mountains, fort, village, valley, forest, time of day, weather, 
mist, sunlight, sky, birds, butterflies, waterfalls, wildflowers]
```

### Layer 3 — Characters (if present)
```
[Character name] [attire description — always historically authentic]:
- Headgear: [turban/helmet with specific detail]
- Robe/Armor: [color, material, embroidery]
- Accessories: [necklace, waist sash, footwear, sword]
- Expression: [calm/determined/confident — never angry/cartoonish]
- Body language: [what they are doing without speaking]
```

### Layer 4 — Action
```
[What happens in the scene — movements, gestures, reactions]
All actions without dialogue. Emotions through posture and expression only.
```

### Layer 5 — Camera Movement
```
Camera Sequence: [Shot 1 description] → [Shot 2] → [Shot 3] → [Final frame]
Examples:
- Ultra-wide aerial drone shot → descending crane → close-up → pullback
- Close-up of [object] → slow dolly → orbit → hero shot
```

### Layer 6 — Technical Quality
```
Ultra-realistic textures, cinematic HDR lighting, volumetric sun rays/god rays, 
realistic cloth simulation, natural wind physics, cinematic depth of field, 
masterpiece composition, [describe audio mood], historically authentic costumes 
and architecture, 8K Ultra HD.
```

## STANDARD NEGATIVE PROMPT

Always include this base, then add scene-specific negatives:

```
Talking, lip sync, moving lips, mouth animation, dialogue, shouting, 
excessive blood, gore, dismemberment, graphic injuries, horror, 
fantasy creatures, modern buildings, modern clothing, vehicles, guns, 
electricity poles, mobile phones, text, subtitles, watermark, logo, 
blur, low quality, distorted anatomy, extra limbs, cartoon comedy, 
oversaturated colors, unrealistic armor.
```

**Add for Kids videos:**
```
battle, sword fighting, blood, violence, explosions, fire, angry expressions.
```

**Add for action scenes:**
```
horror-level gore, body parts, graphic wounds, close-up injuries.
```

## HISTORICAL ACCURACY RULES

1. **Never mix timelines** — e.g., Tanaji's 1670 Sinhagad battle ≠ 1647 Kondhana capture
2. **Add disclaimer** at start of every video:
   ```
   "यह कहानी उपलब्ध ऐतिहासिक स्रोतों पर आधारित है। कुछ दृश्य 
   रचनात्मक प्रस्तुति के उद्देश्य से तैयार किए गए हैं।"
   ```
3. **Costume accuracy by era:**
   - 17th century Maratha: Saffron turban, white robes, steel armor, pearl necklace, peshwai footwear
   - 17th century Bijapur/Adilshahi: Green/red velvet robe, jeweled turban, Persian-influenced armor
4. **Architecture:** Maratha forts = Sahyadri black basalt stone, wooden gates, stone bastions

- Always write full prompt — never truncate
- Never skip Negative Prompt section

- If user says "all scenes" → write all in one response

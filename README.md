# 🎬 AI Cinematic History Video Skill

A reusable skill for generating AI history video prompts for YouTube channels focused on Indian history — specifically the Maratha Empire and Chhatrapati Shivaji Maharaj series.

## 📁 Files

| File | Purpose |
|---|---|
| `SKILL.md` | Main skill file — give this to Claude before starting any video project |

## 🚀 How to Use

1. Open Claude (claude.ai)
2. Paste the contents of `SKILL.md` in your first message
3. Tell Claude: *"Use this skill. I want to make a video about [topic]"*
4. Claude will ask 5 quick questions, then generate all scenes

## ✅ What This Skill Does

- Generates scene-by-scene AI video prompts (Veo 3 / Kling / Seedance ready)
- Enforces No Lip Sync rule automatically
- Keeps voiceover within 8-second timing limits
- Maintains historical accuracy and respectful portrayal
- Produces SEO title + description + hashtags
- Supports 9:16 (Shorts) and 16:9 (Long-form)
- Violence level control: Kids / General / Historical

## 📌 Key Rules Encoded in Skill

1. No lip sync on any character
2. No single-name reference for Chhatrapati Shivaji Maharaj
3. Voiceover word count strictly matched to scene duration
4. Historical disclaimer included in every video
5. Costume and architecture accuracy for 17th century Maharashtra
